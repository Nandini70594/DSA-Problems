## Check If a Word Occurs As a Prefix of Any Word in a Sentence

Given a sentence containing words separated by single spaces and a `searchWord`, return the 1-indexed position of the first word for which `searchWord` is a prefix. If no such word exists, return `-1`.

### Example

Input:
sentence = "i love eating burger"
searchWord = "burg"

Output:
4

"burg" is a prefix of "burger", which is the 4th word.
