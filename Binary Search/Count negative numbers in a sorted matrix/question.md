# Count Negative Numbers in a Sorted Matrix

## Problem Statement

Given an `m × n` matrix `grid` sorted in **non-increasing order** both row-wise and column-wise, return the total number of negative numbers.

### Example 1

**Input**

```text
grid = [
 [4,3,2,-1],
 [3,2,1,-1],
 [1,1,-1,-2],
 [-1,-1,-2,-3]
]
```

**Output**

```text
8
```

### Example 2

**Input**

```text
grid = [
 [3,2],
 [1,0]
]
```

**Output**

```text
0
```
