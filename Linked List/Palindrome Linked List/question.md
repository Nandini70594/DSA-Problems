# Palindrome Linked List

## Problem Statement

Given the head of a singly linked list, determine whether the linked list is a palindrome.

A palindrome is a sequence that reads the same forward and backward.

Return `true` if the linked list is a palindrome; otherwise, return `false`.

### Example 1

**Input**
```
head = [1,2,2,1]
```

**Output**
```
true
```

### Example 2

**Input**
```
head = [1,2]
```

**Output**
```
false
```

### Constraints

- Number of nodes is in the range `[1, 10^5]`
- `0 <= Node.val <= 9`

### Follow-up

Can you solve it in **O(n)** time and **O(1)** extra space?
