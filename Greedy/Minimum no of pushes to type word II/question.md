# Minimum Number of Pushes to Type Word II

## Problem

You are given a string `word` consisting of lowercase English letters.

A telephone keypad has **8 keys (2–9)**, and each letter must be assigned to exactly one key. The first letter on a key requires **1 push**, the second requires **2 pushes**, and so on.

You may remap the letters to the keys in any way. Return the **minimum number of key presses** required to type the given word.
