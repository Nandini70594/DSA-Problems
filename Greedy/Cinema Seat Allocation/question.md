# Cinema Seat Allocation

## Problem

A cinema has `n` rows, and each row contains 10 seats numbered from `1` to `10`.

Some seats are already reserved. A group of 4 people can be seated only in one of these blocks:

- Seats `2-5`
- Seats `4-7`
- Seats `6-9`

A block can be used only if none of its seats are reserved. Find the maximum number of four-person groups that can be seated.
