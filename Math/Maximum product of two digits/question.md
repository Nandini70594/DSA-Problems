# Maximum Product of Two Digits

## Problem Statement

You are given a positive integer `n`.

Return the maximum product of any two digits in `n`.

> Note: The same digit may be used twice only if it appears more than once in the number.

### Example 1

**Input**
```
n = 31
```

**Output**
```
3
```

### Example 2

**Input**
```
n = 22
```

**Output**
```
4
```

### Example 3

**Input**
```
n = 124
```

**Output**
```
8
```

### Constraints

- `10 <= n <= 10^9`
