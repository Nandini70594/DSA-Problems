# Find the Winner of the Circular Game

**LeetCode 1823 — Medium**

## Problem

There are `n` friends sitting in a circle, numbered from `1` to `n`. Starting from friend `1`, every `k`-th friend is eliminated. After a friend is eliminated, counting continues from the friend immediately clockwise to them. The process continues until only one friend remains. Return the position of the winner.

## Example

**Input:**
`n = 5, k = 2`

**Elimination Order:**
`2 → 4 → 1 → 5`

**Output:**
`3`
